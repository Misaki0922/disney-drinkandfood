# なに飲む？

東京ディズニーランドのフリードリンク券が使える23店を、飲みものとフードから逆引きするツールです。
2026年9月22日（火）に買えるメニューだけを載せています。

## GitHubで公開する手順

1. GitHubで新しいリポジトリを作る（Publicにする。Privateだと無料プランではページを公開できません）
2. このフォルダの中身をすべてアップロードする
   - リポジトリのトップ画面 → **Add file** → **Upload files** → ファイルをまとめてドラッグ → **Commit changes**
   - フォルダごとではなく、`index.html` などのファイルが**リポジトリの直下**に来るようにしてください
3. リポジトリの **Settings** → 左メニューの **Pages** を開く
4. Source を **Deploy from a branch**、Branch を **main** と **/ (root)** にして **Save**
5. 1〜2分待つと、Pagesの画面に `https://ユーザー名.github.io/リポジトリ名/` というURLが出ます

## iPhoneのホーム画面に置く

1. **Safariで**そのURLを開く（Chromeだとホーム画面に追加できません）
2. 下の共有ボタン（□に↑）をタップ
3. メニューを下にスクロールして **ホーム画面に追加**
4. 名前は「なに飲む？」で入っています。**追加** をタップ

追加したアイコンから開くと、Safariのアドレスバーが出ない全画面表示になります。
一度開いておけば、パーク内で電波が悪くてもそのまま使えます。

## 中身を書き換えたとき

`index.html` を直して再アップロードしたあと、**`sw.js` の1行目の `CACHE` の日付も変えてください**。
これを変えないと、ホーム画面のアイコンから開いたときに古い内容が表示され続けます。

```js
const CACHE = "freedrink-2026-09-01";  // ← ここを新しい日付に
```

変えたあとホーム画面のアイコンから開き直すと、新しい内容に入れ替わります。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ツール本体。データもこの中に全部入っています |
| `manifest.webmanifest` | ホーム画面用のアプリ名・アイコン・全画面設定 |
| `sw.js` | オフラインで開けるようにする仕組み |
| `apple-touch-icon.png` | iPhoneのホーム画面アイコン（180px） |
| `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` | Android・その他用のアイコン |
| `favicon.png` | ブラウザのタブに出る小さいアイコン |
| `.nojekyll` | GitHub Pagesの余計な変換を止めるための空ファイル |
